═══════════════════════════════════════════════════════════
   UTILISATION RAPIDE
═══════════════════════════════════════════════════════════

1. Test manuel immédiat :
   ./scripts/monitor-symbion.sh

2. Installation automatique avec cron :
   ./scripts/install-monitoring.sh

3. Configuration email (optionnel) :
   cp scripts/config-mail-example.conf ~/.msmtprc
   chmod 600 ~/.msmtprc
   nano ~/.msmtprc  # Configurer vos credentials

4. Test avec email :
   ./scripts/monitor-symbion.sh votre-email@example.com

═══════════════════════════════════════════════════════════
   SURVEILLANCE AUTOMATIQUE
═══════════════════════════════════════════════════════════

Le script vérifie automatiquement :
• Kernel alive (http://localhost:8080)
• MQTT status (connected/disconnected)
• Agents online/offline + métriques
• Plugins running/failed

Envoie des alertes mail pour :
• Kernel DOWN
• MQTT déconnecté
• Tous agents offline
• Plugin crashed
• Système récupéré
